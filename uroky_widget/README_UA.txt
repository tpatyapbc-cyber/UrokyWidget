ВІДЖЕТ «УРОКИ» — БЕЗКОШТОВНА ЗБІРКА APK У БРАУЗЕРІ

ЩО ЦЕ
Android-віджет із 4 кнопками. Натискання кнопки відкриває відповідне посилання Google Meet.

Кнопки:
1. Англійська
2. Інформатика
3. Музичне мистецтво
4. Інші предмети

ЯК ОТРИМАТИ APK БЕЗ ANDROID STUDIO

Варіант через GitHub — безкоштовно для публічного репозиторію:

1. У браузері відкрий https://github.com/ і створи безкоштовний акаунт або увійди.
2. Натисни + → New repository.
3. Назва: UrokyWidget
4. Вибери Public.
5. Створи репозиторій.
6. У репозиторії натисни Add file → Upload files.
7. Розпакуй цей ZIP на телефон/комп'ютер і завантаж УСІ файли та папки з нього в репозиторій. Папку .github теж потрібно завантажити.
8. Натисни Commit changes.
9. GitHub автоматично запустить Actions → Build APK.
10. Відкрий вкладку Actions → Build APK → останній запуск.
11. Внизу сторінки знайди Artifacts → Uroky-widget-debug-apk і завантаж ZIP.
12. Розпакуй його — всередині буде app-debug.apk.
13. Встанови APK на Android. Якщо телефон попросить дозвіл на встановлення з цього джерела, дозволь браузеру/файловому менеджеру встановлення.
14. Додай віджет «Уроки» на головний екран.

ВАЖЛИВО
- Нічого платити не потрібно, якщо використовувати публічний GitHub-репозиторій.
- Android Studio для цього способу не потрібен.
- APK є debug-збіркою, для власного телефону цього достатньо.
- Якщо GitHub попросить підтвердити запуск Actions, відкрий Actions і дозволь workflow.
